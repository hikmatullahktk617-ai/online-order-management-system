# online-order-management-system

The online order management system is a SQL server based database project designed to manage the complete Order 
process of an online shopping business. the system handle customers products categories orders payments and inventory management 
in organized and automated way.

in this project customers can place orders for products, and the system automatically stores order details calculates total 
update payment information and reduces stock quantity after each purchase. this project also include reports and views to analyize sales product performances and customer order history.


this project is useful for learning purpose:

1. Database design 
2. SQL queries
3. Store procedures
4. Inventory management logic
5. Github processing workflows
6. version control using GIT
7. Order processing workflows


Key feature of this project:
1. Customer management 
2. Product & category Management
3. Order placement system
4. Automatic stock update
5. payment tracking
6. Sales report
7. Order status Management
